# DSGBench Overview

**DSGBench** is a diverse strategic game benchmark for evaluating LLM-based agents in complex decision-making environments. It provides six high-dynamics game environments with fine-grained, multi-dimensional evaluation metrics.

## Paper

> **DSGBench: A Diverse Strategic Game Benchmark for Evaluating LLM-based Agents in Complex Decision-Making Environments**
>
> Wenjie Tang, Yuan Zhou, Erqiang Xu, Keyan Cheng, Minne Li, Liquan Xiao
>
> [📄 arXiv:2503.06047](https://arxiv.org/abs/2503.06047)

## Evaluation Dimensions

DSGBench evaluates agents across four key capability dimensions:

| Dimension | Description | Primary Games |
|-----------|-------------|---------------|
| **Strategic Planning** | Long-horizon goal setting and execution | Civilization, StarCraft II |
| **Real-time Decision** | Rapid tactical responses under time pressure | StarCraft II, Street Fighter III |
| **Adaptability** | Adjusting strategy based on changing environment | All games |
| **Multi-agent Interaction** | Cooperation, competition, and negotiation | Diplomacy, Werewolf |
